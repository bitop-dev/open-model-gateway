Notes for changes on `main` after [v0.19.0](v0.19.0.md). They become the next release's notes.

## Pricing drafts

OpenRouter operator price previews apply their structural limits only to the catalog fields the mapper reads, so speech models with long voice lists and endpoints with many unread fields are priced instead of returned as all-unknown drafts; endpoint lists of up to 256 endpoints are compared (#741). Read fields keep their limits and an over-limit endpoint response is not cached. An endpoint with comparable rates and an unreadable status is reported when it is left out of the cheapest choice, the endpoint warnings state the input and output rates that were compared, and the warning that names the endpoint a draft was priced from is never omitted. Endpoint rates in warnings are worded in the workload's units (tokens, input characters, or units where the unit is model-specific), and a catalog fallback caused by unreadable endpoint statuses says so. Provider labels are reduced to printable ASCII and fall back to the endpoint tag; a label that filtering changed, or that two endpoints share, names the endpoint's position. Each endpoint's read fields have their own value budget, and the endpoints document is projected from the response bytes without building a value tree. The catalog fetch runs one upstream request at a time, within each preview's 5-second deadline (time spent waiting included); previews waiting on a fetch that fails share its failure, and the cache holds at most 16 MiB.
